# FitShop 🏋️‍♂️

FitShop is an advanced e-commerce web application tailored for fitness enthusiasts. It offers a wide range of fitness products, a seamless shopping experience, and innovative AI-powered features such as dynamic workout plan generation.

## Features
- Extensive catalog of fitness products
- Add/remove items in the shopping cart
- Secure user authentication (login/signup)
- Smooth checkout process
- Responsive, mobile-friendly UI
- Dynamic AI workout plan & product suggestions (Ninja API)
- Clean navigation and user-friendly design

## AI Features
FitShop leverages AI to deliver a personalized, smart fitness shopping journey:

### Dynamic Workout Plan & Product Suggestions via Ninja API
- Select your **fitness goal, muscle group, and fitness level**
- Instantly generate a tailored workout plan (exercises, sets, reps, and tips) using the Ninja API
- Along with the workout plan, receive **product recommendations** (supplements, gear, or equipment) specific to your chosen muscle group
- Designed to save you time, boost motivation, and guide you with the right fitness essentials
- Plans and products are displayed in a clean, easy-to-follow format directly inside the app
